# GIYERA SA BUENLAG NI LUCAS

**Made by JMC Labs • Made for Lucas the Pogi**

A 3D mobile first-person tactical shooter (FPS) built with Three.js and Capacitor Android, featuring 5-player single-host LAN/network war mode, 5 colorful battle terrains, animated male and stylized Lady Operative characters, tactical armory (`₱` credits), and automated Android APK builds via GitHub Actions.

## GitHub Repository Name

When creating or renaming the repository on GitHub, use:
- **Repository name**: `giyera-sa-buenlag-ni-lucas`

## Features

- **5 Battle Terrains**: Desert Concrete, Neon Tile Yard, Red Brick Bastion, Steel Shipyard, and Jungle Compound.
- **Characters**: Male Soldier (Lucas) & stylized Lady Operative with customizable uniforms, country patches, and uploaded face caricature support.
- **Tactical Armory (₱)**: Combat Drone, Frag Grenades, Anti-Drone EMP, Spread Bullet Shotguns, and heavy rifles.
- **Network War Mode**: Up to 5 players in a single-host room, with optional country-army AI bots.
- **Mobile & Desktop Controls**: Dual-thumb touch controls (floating analog stick, drag-look, FIRE, ADS, JUMP, RELOAD, LOOK BACK) plus desktop WASD + PointerLock.

## Build Android APK (GitHub Actions)

Every push triggers `.github/workflows/build-apk.yml` (`GIYERA SA BUENLAG NI LUCAS - Build Android APK`), outputting:
- **Artifact**: `GiyeraSaBuenlagNiLucas-APK` (`GiyeraSaBuenlagNiLucas.apk`)
- **Tag Release** (`v*`): Publishes `GiyeraSaBuenlagNiLucas.apk` to GitHub Releases.
